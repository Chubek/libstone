# Generated backend data

These Lua modules contain JSON extracted from LLVM TableGen specifications
and selected Ghidra SLEIGH/compiler specifications. The extraction tool and
source fingerprints are recorded in each document. Regenerate with
`../tools/extract_backend.py`; see `../README.md` for the consumer schema.

LLVM source material is part of the LLVM Project, licensed under
**Apache-2.0 WITH LLVM-exception**:
<https://github.com/llvm/llvm-project/blob/llvmorg-22.1.8/LICENSE.TXT>.

Ghidra source material is part of the Ghidra project, licensed under
**Apache-2.0**:
<https://github.com/NationalSecurityAgency/ghidra/blob/master/LICENSE>.
Processor sources are under `Ghidra/Processors` in that repository.

Supplementary compiler policies cite their upstream source URLs in
`../tools/backend_policies.json` and in each applicable emitted document.
