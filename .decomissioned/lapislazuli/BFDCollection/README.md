# BFDCollection

Nine structural ELF target profiles generated by
[BFDWeave](../Weavers/BFDWeave/README.md), using `.info/binutils` backend target
names, `EM_*` definitions and ELF external layouts as references.

| Profile | Binutils target | Class / endian | EM number |
| --- | --- | --- | --- |
| ELF32_ARM_LE | elf32-littlearm | 32 / little | 40 |
| ELF32_I386_LE | elf32-i386 | 32 / little | 3 |
| ELF32_MIPS_BE | elf32-bigmips | 32 / big | 8 |
| ELF32_MIPS_LE | elf32-littlemips | 32 / little | 8 |
| ELF32_PPC_BE | elf32-powerpc | 32 / big | 20 |
| ELF32_SPARC_BE | elf32-sparc | 32 / big | 2 |
| ELF64_PPC_BE | elf64-powerpc | 64 / big | 21 |
| ELF64_SPARC_BE | elf64-sparc | 64 / big | 43 |
| ELF64_X86_64_LE | elf64-x86-64 | 64 / little | 62 |

Each `NAME/NAME.bfdw` generates a matching public header and implementation.
Readers handle headers, sections, program segments, names and borrowed payload
spans. They do **not** implement the full named binutils backend or its ABI
checks, relocations, symbols, archives, linker or writer. BFD architecture
identity and ELF machine IDs are distinct (x86-64 belongs to BFD's i386 family).

```c
#include "BFDCollection/ELF32_MIPS_BE/ELF32_MIPS_BE.h"
#include "ArchCollection/MIPS32/MIPS32.h"

/* The caller supplies a complete immutable ELF buffer and a section index. */
int decode_first(const void *bytes, size_t size, uint64_t section_index,
                 MIPS32_decoded *out) {
    ELF32_MIPS_BE_view view;
    const void *code;
    size_t length;
    int status = ELF32_MIPS_BE_open(bytes, size, &view);
    if (status) return status;
    status = ELF32_MIPS_BE_section_data(&view, section_index, &code, &length);
    if (status) return status;
    if (length < 4) return -2;
    return MIPS32_decode(code, length, 0, out);
}
```

The caller must select an executable, uncompressed section of the appropriate
ISA; the reader does not infer this from bytes. Link the two profile `.c` files.

```sh
lua5.4 BFDCollection/regenerate.lua --list
lua5.4 BFDCollection/regenerate.lua ELF64_X86_64_LE
lua5.4 BFDCollection/regenerate.lua --check
python3 test_collections.py
```

To add a target, cite the local backend and machine definition in a `.bfdw`,
regenerate and test. The generic test runner exercises every discovered target
with class/endian-specific fixtures, extended counts, malformed files and an
ELF-to-ArchWeave handoff where a native codec exists.
