Exotract source overlay for Chubek/libstone
==========================================

Unpack this ZIP into the LibStone repository root.
It creates moonstone/exotract/ (no existing LibStone files overwritten).
See moonstone/exotract/README.md and STATUS.md.

NOTE: This archive contains original Exotract source only. It intentionally
omits LibStone and third_party vendor code. The optional vendor components
could not be exercised in the standalone packaging environment, so the
artifact is an implemented and tested core, NOT an audited production release.
